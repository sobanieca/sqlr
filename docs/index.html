Run a query before your database GUI finishes loading.

sqlr is a small terminal client for SQL. Save a connection once, then run queries, describe tables and pipe results wherever you need them.

The first argument is either SQL or a path to a .sql file. {{ variables }} in the file are filled from -i "key: value".

Describe the schema

sqlr describe --compact prints tables, columns, types and foreign keys in a form that fits in a prompt.

Three output shapes

Compact rows by default, --table for humans, -o result.json for files and scripts.

Scoped per repository

Connections belong to the git repo you are in. -g uses the global scope instead.

No prompts in CI

Every command takes flags, so pipelines and cron jobs can run it without an interactive wizard.

AI agents query by name. The connection string never enters their context.

Add the connection yourself, set it as default, and let the agent run sqlr. It sees table names and rows, not hosts, users or passwords.
